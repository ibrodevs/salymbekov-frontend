# Обновление frontend по ТЗ

Реализованы переименования Нарын кампуса и точных упоминаний Высшей школы медицины → ИГН; отдельный Международный факультет медицины сохранён. Добавлены страницы `/education/student`, `/education/applicant`, CMS-страница `/education`, хлебные крошки, RU/EN/KG, сохранение выбранного языка при переходах по HTML-ссылкам из CMS. Дизайн новых страниц использует существующие градиенты, типографику и карточки сайта; содержимое задаёт backend CMS.

Последипломный раздел убран из всех вариантов Navbar. На `/education/postgrad` и весь его поддеревья Vercel возвращает HTTP 301 → `/education`; React-router обеспечивает такой же переход при внутренней SPA-навигации. `/contacts` перенаправляется на `/contact`.

На странице контактов добавлена самостоятельная форма анонимного обращения. Имя и email необязательны, обязательные subject/message ограничены по длине, предусмотрены состояния отправки/ошибки/успеха/429, защита от повторной отправки и honeypot. Перед запуском настроить SMTP в backend по его инструкции. Обращения не публикуются.

Обычные и legacy CMS-шаблоны добавляют нижнюю галерею только при явном включении в CMS. Исключаются использованные в rich text, секциях и hero изображения, повторные URL с параметрами/CDN-доменами и одинаковые media ID. Оригиналы не удаляются. `/MaterialBaseGallery` сохраняется миграцией backend.

## Запуск и проверки

```sh
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

`npm run dev` — разработка. Backend URL берётся из VITE_API_URL; по умолчанию dev использует localhost:8000/api, production — существующий backend проекта.

Unit: 14 тестов. E2E: 10 тестов production-preview (desktop и mobile, контролируемые API-ответы). Проверяются навигация, редиректы, языки, обязательные поля, отправка без контактов, retry, 429, блокировка дубликатов, отсутствие JS-исключений и горизонтального overflow.

Дополнительно с реально запущенной локальной/staging CMS:

```sh
npm run preview -- --host 127.0.0.1
CMS_API_URL=http://127.0.0.1:8000/api node scripts/verify-cms.mjs
```

Скрипт ничего не отправляет по почте. Проверяет 3 страницы × 3 языка × 2 ширины, SEO title, число CMS-секций, отсутствие JS-исключений и overflow; создаёт снимки в игнорируемой папке test-results.

Перед production проверить оба репозитория совместно, реальные HTTP 301 на хостинге, получателя SMTP и утверждённый контент. Локальная CMS не заменяет базу production. Инструкция обновления/резервирования CMS находится в backend `docs/UNIVERSITY_UPDATE_2026.md`.

Эти вопросы требуют отдельной работы с существующей кодовой базой.
